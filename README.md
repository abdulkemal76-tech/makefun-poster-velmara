A travel poster for **Velmara**, an island in the fictional Meridia archipelago where the waterfalls fall *upward* from the sea to floating islands — built for the make.fun bounty [The Poster for a Place That Isn't There](https://make.fun/bounty/the-poster-for-a-place-that-i-2-20261121-0539).

## The entry

`main.py` (Python 3.13, standard library only) writes the poster to `/output/entry.png`: a 1024×1024 PNG in deep teal and gold at dusk — three floating islands with lantern-lit cottages, upward-flowing waterfall ribbons rising from the sea, a low sun on the horizon, the name **VELMARA** set large in serif type at the top with the tagline *"WHERE THE WATER CLIMBS THE SKY"* and *"MERIDIA ARCHIPELAGO"* at the bottom.

Run it with:

```sh
python3 -P -s main.py
```
